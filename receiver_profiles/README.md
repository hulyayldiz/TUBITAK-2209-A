# Alıcı profilleri

Bu dizine yalnız `calibrate_receiver.py` ile ayrı normal oturum kontrolünü geçen
alıcı profilleri kurulur. Şu anda ek bir gerçek donanım profili kurulmuş değildir.
Bilinen eski GRID profili `models/texbat_grid_profile.json` dosyasında kalır.

Kimlik/kullanım eşleştirmesi, CSV alanları, komutlar ve sınırlar için
[alıcı profili kılavuzuna](../RECEIVER_PROFILES.md) bakın. Testlerde üretilen sentetik
profiller bu dizine konmaz.
